# 06 · CRM screens (`/crm`)

Same tokens as the website (ink/navy/steel, signal orange, Geist), dark, dense, keyboard-first. Desktop sidebar; mobile bottom tabs (Ken uses his phone). No "AI" wording in the UI — the agent appears as **"Assistant"**, state per lead is **Auto / Manual**, button **Take over**.

| Screen | What's on it |
|---|---|
| **Dashboard** | Funnel (contacted → replied → interested → form sent → applied → hired), today's replies/forms, response time, agent actions today, campaign health (sent, open, reply, bounce per campaign + variant), cost (DeepSeek $, Quo credits) |
| **Inbox** (unified) | All email + text threads in one list, filters (needs human, unread, channel, stage), live via Realtime; reply as email or text from one box; agent drafts shown in grey before send window ("sending in 4 min — edit / cancel") |
| **Pipeline** | Kanban by stage, drag to move, cards show last message + form progress bar + time since last touch |
| **Contacts** | Table of 20k with search, filters (tier, state, stage, tag, consent), bulk actions (add to campaign, tag, assign) |
| **Lead profile** | Left: info, consent, tags, stage, owner. Center: **one timeline** — emails, texts, calls (recording + transcript), form steps, stage moves, opens/clicks, notes. Right: Assistant memory (facts + summary + next step), upcoming follow-ups, agent run log, Take over / Resume, Call (Quo), Send form |
| **Campaigns** | List with live stats, sequence + variants editor, A/B results, wave scheduler, push leads by tier |
| **Automations** | Workflow list + builder, run history per workflow |
| **Assistant** | On/off, quiet hours, delays, max messages, offer facts, voice examples, test console (paste a message, see the reply) , weekly review (👍/👎) |
| **Forms** | Form link stats: sent, opened, step drop-off, completed |
| **Settings** | Team & roles (admin / recruiter / Ken = client view), integrations status (Instantly, Quo, DeepSeek, Resend keys valid, webhooks last received), import CSV, suppression list |

**Ken's view:** only Applied+ leads and replies flagged for him, his tasks, one-tap call/text.
